# Zubair Portfolio CMS

A modern Full Stack Portfolio Website built with the MERN Stack. It includes a beautiful portfolio frontend and a secure admin dashboard where projects and portfolio content can be managed dynamically.

---

## 🌐 Live Demo

### Portfolio
https://zubair-portfolio-phi.vercel.app/

### Backend API
https://codealpha-portfolio-1.onrender.com/

---

# ✨ Features

## Portfolio

- Responsive Design
- Modern UI
- Hero Section
- About Section
- Skills Section
- Experience
- Internship
- Projects
- Certificates
- Resume Download
- Contact Section

---

## Admin Dashboard

- Secure JWT Authentication
- Admin Login
- Add Projects
- Edit Projects
- Delete Projects
- Upload Images using Cloudinary
- Dynamic Portfolio Management

# ⚙ Installation

## Clone Repository

```bash
https://github.com/Zubair673/CodeAlpha-Portfolio.git
```

## Install Frontend

```bash
cd client
npm install
npm start
```

## Install Backend

```bash
cd server
npm install
npm start
```

---

# 🔑 Environment Variables

Create a `.env` file inside the server folder.
